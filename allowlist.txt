# 手動白名單：這裡的網域永遠不會出現在最終清單
#
# 寫法：
#   example.com        只放行 example.com 本身
#   *.example.com      放行 example.com 以及它所有子網域
#   ||example.com^     同上（AdBlock 寫法）
#
# 原則：只放「擋了會讓一般使用壞掉」的網域；廣告/追蹤子網域
# （如 googleadservices.com、doubleclick.net）是不同網域，不受影響。
# 發現誤擋時，直接在這裡加一行並 push，下次建置就會生效。
